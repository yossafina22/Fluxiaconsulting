# Fluxia Consulting — Dossier final V3

## Contenu
- `CLAUDE.md` : cahier des charges complet.
- `prompt_claude_code.md` : instruction d'exécution pour Claude Code.
- `public/brand/logo.svg` : logo original complet.
- `public/brand/logo-icon.svg` : icône originale.
- `references/maquette-accueil-validee.png` : deuxième maquette validée.

## Installation
1. Créer/ouvrir le dépôt Next.js dans Claude Code.
2. Copier **tous** les fichiers du dossier à la racine du dépôt, en conservant les sous-dossiers.
3. Demander à Claude Code : « Lis CLAUDE.md et exécute prompt_claude_code.md, en respectant la deuxième maquette et les SVG fournis. »
4. Fournir ensuite les accès et clés API des fournisseurs choisis (LLM, ElevenLabs, calendrier, envoi d'e-mails, hébergement), **uniquement via variables d'environnement sécurisées**.

## À valider avant mise en ligne
- Disponibilité du domaine et DNS ; horaires et calendrier des consultations ; consentement voix/cookies ; politique de confidentialité et Impressum ; informations juridiques d'immatriculation ; fournisseur de messagerie et CRM.
- Les réservations et agents IA ne doivent pas être annoncés comme opérationnels avant intégration et test.
- Le nom commercial textuel est « Fluxia Consulting » ; le logo SVG fourni affiche « Fluxia-consulting ». Ne pas retoucher le fichier sans validation explicite.
- La maquette est une référence de direction artistique, pas une capture du site réalisé.
